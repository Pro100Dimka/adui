# Архитектура компонентов A&D Voice UI

Главное правило библиотеки: **один React-компонент = один файл компонента**.

## Иерархия

```text
packages/ui/src/
├─ components/
│  ├─ index.ts
│  ├─ layout/
│  │  ├─ index.ts
│  │  ├─ Card/
│  │  │  ├─ index.ts
│  │  │  └─ Card.tsx
│  │  ├─ Surface/
│  │  │  ├─ index.ts
│  │  │  └─ Surface.tsx
│  │  └─ ...
│  ├─ controls/
│  │  ├─ index.ts
│  │  ├─ Button/
│  │  │  ├─ index.ts
│  │  │  └─ Button.tsx
│  │  └─ ...
│  ├─ feedback/
│  ├─ media/
│  │  └─ RotaryKnob/
│  │     ├─ index.ts
│  │     └─ RotaryKnob.tsx
│  ├─ compositions/
│  └─ editor/
└─ core/
   ├─ providers/
   │  ├─ ThemeProvider/
   │  └─ MotionProvider/
   └─ motion/
      └─ AnimatedBorder/
```

## Зачем `index.ts` на каждом уровне

Компонент импортируется через его папку, а не через внутренний файл:

```ts
import { Button } from "./Button";
```

Категория собирает компоненты своим barrel-файлом:

```ts
export * from "./Button";
export * from "./TextField";
```

А корневой `components/index.ts` собирает категории.

Так внутреннее расположение можно менять без переписывания всех импортов приложения.

## Shared-файлы

`shared.tsx` внутри категории содержит только общие типы, контексты и helper-функции категории. React-компонентов в нём нет.

Например `controls/shared.tsx` может содержать `ButtonProps`, `FieldContext` или общий helper отрисовки, но `Button`, `TextField`, `Slider` и другие компоненты живут каждый в своей папке.

## Проверка структуры

```bash
npm run check:structure
```

Проверка падает, если:

- у компонента нет собственной папки;
- отсутствует `index.ts`;
- отсутствует `<Component>.tsx`;
- в одном component-файле объявлено больше одного публичного компонента.

`CHECK_ALL.cmd` запускает эту проверку автоматически.

## Добавление нового компонента

Например `PitchKnob`:

```text
components/media/PitchKnob/
├─ index.ts
└─ PitchKnob.tsx
```

`PitchKnob.tsx`:

```tsx
export interface PitchKnobProps {
  value: number;
}

export function PitchKnob({ value }: PitchKnobProps) {
  return <div>{value}</div>;
}
```

`PitchKnob/index.ts`:

```ts
export { PitchKnob } from "./PitchKnob";
export type { PitchKnobProps } from "./PitchKnob";
```

И в `media/index.ts`:

```ts
export * from "./PitchKnob";
```

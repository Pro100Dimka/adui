# Архитектура компонентов

Правило библиотеки: отдельный компонент существует только когда у него есть собственная повторно используемая семантика или поведение.

- `TextField` отвечает за обычный текстовый ввод и adornments.
- `Field` — низкоуровневый input base.
- `Card` — единая поверхность (`material`) и опциональная анимированная рамка (`border`).
- `Header` — один заголовок для page/section/dialog/card.
- `Icon` — обычная иконка и `surface="tile"`.
- `Illustration` — SVG и `framed` режим.
- `PianoRollGrid` владеет внутренними деталями melody editor.
- Экранные одноразовые композиции не становятся компонентами UI-kit.

У каждого публичного компонента одна папка: implementation + styles + example + meta. Локальных barrel `index.ts` нет.

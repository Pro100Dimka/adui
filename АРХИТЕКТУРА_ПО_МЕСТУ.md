# Всё по месту

Компонент правится из одной папки:

```text
RotaryKnob/
├─ RotaryKnob.tsx
├─ styles.css
├─ example.tsx
├─ meta.ts
└─ index.ts
```

`example.tsx` автоматически попадает в каталог, `meta.ts` хранит описание/категорию. Центральных `examples.tsx` и `component-manifest.json` больше нет.

Общее допускается только в соседнем `_shared/`, если им действительно пользуются несколько компонентов.

Экраны тоже собраны по папкам:

```text
screens/settings/
├─ index.ts
├─ layout.json
├─ artwork.json
├─ styles.css
└─ controller.js
```

`components.css` — только generated entry. Вручную стили меняются в `styles.css` рядом с компонентом.

## Добавить новый компонент

```bash
npm run create:component -- media PitchKnob "Регулятор высоты тона"
```

Команда сама создаёт `Component.tsx`, `styles.css`, `example.tsx`, `meta.ts`, `index.ts` и добавляет экспорт категории.

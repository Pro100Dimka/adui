# Colocation

Правишь примитив — открываешь одну папку. Пример: `components/controls/TextField/` содержит реализацию, CSS, live example и meta.

Не создавай `CopyableTextField`, `PathTextField`, `SettingsHeader`, `MetricCard` и подобные обёртки. Сначала проверь, можно ли выразить случай через props/adornments/composition существующих примитивов.

# Как работать с A&D Voice UI

## Один раз после распаковки

Установи Node.js 20+ и запусти:

```bash
npm install
```

На Windows можно просто дважды нажать `START_DEV.cmd` — он сам выполнит `npm install`, если это первый запуск.

## 1. Меняешь UI

Запусти:

```bash
npm run dev
```

Откроется React-приложение с двумя разделами:

- **Компоненты** — каталог всех элементов библиотеки;
- **Экраны** — реальные экраны A&D Voice, собранные из этих компонентов.

Исходники UI находятся здесь:

```text
packages/ui/src/
```

Меняешь компонент или CSS → сохраняешь файл → браузер обновляется автоматически.

## 2. Проверяешь

```bash
npm run typecheck
npm run build
```

Или дважды нажми `CHECK_ALL.cmd`.

## 3. Создаёшь npm-пакет

```bash
npm run package
```

Или дважды нажми `CREATE_NPM_PACKAGE.cmd`.

В `release/` появится:

```text
ad-voice-ui-0.1.0.tgz
```

## 4. Ставишь в караоке

Из проекта караоке:

```bash
npm install C:\путь\к\ad-voice-ui-dev-workspace\release\ad-voice-ui-0.1.0.tgz
```

Использование:

```tsx
import { Button, Card, TextField } from "@ad-voice/ui";
import "@ad-voice/ui/styles.css";
```

## Новая версия пакета

Самый простой вариант:

```bash
npm run release:patch
```

Например, `0.1.0` станет `0.1.1`, после чего новый `.tgz` автоматически попадёт в `release/`.

На Windows для этого есть `CREATE_PATCH_RELEASE.cmd`.

## Код примеров в каталоге

Код под каждым live-примером теперь строится **автоматически из того же JSX**, который реально рендерит этот пример в `apps/playground/src/catalog/examples.tsx`. Поэтому после изменения примера документация не должна расходиться с тем, что видно сверху.

Например, если `Surface` содержит заголовок и описание, каталог покажет `Surface` вместе с этими дочерними элементами, а не сокращённое `<Surface />`. Кнопка **«Копировать весь пример»** копирует полный пример с импортами и нужным React state.

`npm run check:catalog` проверяет, что у всех 86 компонентов есть живой пример. `CHECK_ALL.cmd` запускает эту проверку автоматически. Классы `sample-*` относятся только к расположению элементов внутри playground и не являются частью `@ad-voice/ui`.

## RotaryKnob

В библиотеку добавлена премиальная процедурная крутилка `RotaryKnob`.

```tsx
import { RotaryKnob } from "@ad-voice/ui";

<RotaryKnob
  value={volume}
  onValueChange={setVolume}
  onValueCommit={saveVolume}
  label="Громкость"
/>;
```

Она показана в каталоге в трёх размерах и используется внутри `ParticipantCard` там, где управление действительно должно быть крутилкой.
Подробный API: `packages/ui/docs/ROTARY_KNOB.md`.

## RotaryKnob

Исходник визуала и поведения: `packages/ui/docs/premium-knob-interactive-neon.reference.html`.
`RotaryKnob` — его прямой React-порт. `CircularGauge` — только read-only вариант того же самого регулятора.
Для проверки открой каталог и найди RotaryKnob: он должен реагировать на круговой drag, drag из центра, внешнюю шкалу, колесо, клавиатуру, Shift, Escape и double-click.
